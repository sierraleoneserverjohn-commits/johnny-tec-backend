# Sierra Leone Server (SLS) - Deployment & Installer

The official installer and runtime orchestrator for Sierra Leone Server.

## Repositories
* **API Backend**: `sls-api`
* **Dashboard Frontend**: `sls-dashboard`
* **System Daemon**: `sls-daemon`
* **Deployer**: `sls-deploy`

## Quick Start Installation

```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/sls-deploy.git](https://github.com/YOUR_GITHUB_USERNAME/sls-deploy.git)
cd sls-deploy
chmod +x install.sh start-all.sh
./install.sh
./start-all.sh
